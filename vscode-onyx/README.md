# Onyx Language

Official VS Code extension for **Onyx**.

## Features

- **Syntax highlighting** for keywords, types, functions, strings, numbers
- **Bracket matching** for `()`, `{}`, `[]`
- **Comment toggling** with `Ctrl + /` (line) and `Shift + Alt + A` (block)
- **Error markers** in the Problems panel (via `Onyx: Check File` task)
- **Auto-indentation** inside blocks

## Usage

Open any file with the `.onyx` extension. The extension activates automatically.

## Requirements

- Python 3.10+
- The Onyx compiler files in your project

## Development

1. Open the `vscode-onyx` folder in VS Code.
2. Press `F5` to launch a test window.
3. Open any `.onyx` file in the new window.
