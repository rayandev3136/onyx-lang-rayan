# Contributing to Onyx

Thanks for your interest in Onyx!

## How to contribute

1. **Fork** the repository
2. **Create a branch** for your change
3. **Make your changes**
4. **Test them**
5. **Submit a Pull Request**

## Code style

- Python: follow PEP 8
- Onyx: 4-space indentation

## Reporting bugs

Please include:
- What you expected
- What happened
- A minimal example that reproduces the bug
- Your Python version and OS

## Suggesting features

Open an issue describing:
- The problem you want to solve
- Why it matters
- Any ideas you have
